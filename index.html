Quickstart Guide

Get up and running in seconds.

1. Clone the repository:

git clone https://github.com/urb3x/webscanner.git cd webscanner

2. Run with Python (No third-party packages required):

python local_web_scanner.py

3. Or launch the standalone binary directly:

.\LocalWebScanner.exe
